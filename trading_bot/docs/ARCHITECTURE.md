### 7. Complete Trading Cycle

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              MAIN TRADING LOOP                                  │
│                                                                                 │
│    ┌─────────────────────────────────────────────────────────────────────┐     │
│    │                         EVERY N SECONDS                              │     │
│    └─────────────────────────────────────────────────────────────────────┘     │
│                                      │                                          │
│                                      ▼                                          │
│    ┌─────────────────────────────────────────────────────────────────────┐     │
│    │ 1. CHECK RISK LIMITS                                                │     │
│    │    └─► If breached → HALT TRADING                                   │     │
│    └─────────────────────────────────────────────────────────────────────┘     │
│                                      │                                          │
│                                      ▼                                          │
│    ┌─────────────────────────────────────────────────────────────────────┐     │
│    │ 2. FOR EACH SYMBOL:                                                 │     │
│    │    ┌────────────────────────────────────────────────────────────┐   │     │
│    │    │ a. Fetch latest OHLCV data                                 │   │     │
│    │    │ b. Generate features                                       │   │     │
│    │    │ c. Get ML prediction                                       │   │     │
│    │    │ d. Apply strategy logic                                    │   │     │
│    │    │ e. Generate signal                                         │   │     │
│    │    └────────────────────────────────────────────────────────────┘   │     │
│    └─────────────────────────────────────────────────────────────────────┘     │
│                                      │                                          │
│                                      ▼                                          │
│    ┌─────────────────────────────────────────────────────────────────────┐     │
│    │ 3. SIGNAL CHANGED?                                                  │     │
│    │    └─► No  → Continue to next symbol                                │     │
│    │    └─► Yes → Process signal                                         │     │
│    └─────────────────────────────────────────────────────────────────────┘     │
│                                      │                                          │
│                                      ▼                                          │
│    ┌─────────────────────────────────────────────────────────────────────┐     │
│    │ 4. PROCESS SIGNAL:                                                  │     │
│    │    ┌────────────────────────────────────────────────────────────┐   │     │
│    │    │ • Signal = 1 (BUY)  → Close short, Open long               │   │     │
│    │    │ • Signal = -1 (SELL) → Close long, Open short              │   │     │
│    │    │ • Signal = 0 (HOLD) → Close any position                   │   │     │
│    │    └────────────────────────────────────────────────────────────┘   │     │
│    └─────────────────────────────────────────────────────────────────────┘     │
│                                      │                                          │
│                                      ▼                                          │
│    ┌─────────────────────────────────────────────────────────────────────┐     │
│    │ 5. RISK VALIDATION                                                  │     │
│    │    └─► Calculate position size, stop loss, take profit              │     │
│    │    └─► Check if trade allowed                                       │     │
│    └─────────────────────────────────────────────────────────────────────┘     │
│                                      │                                          │
│                                      ▼                                          │
│    ┌─────────────────────────────────────────────────────────────────────┐     │
│    │ 6. EXECUTE ORDER                                                    │     │
│    │    └─► Submit to exchange                                           │     │
│    │    └─► Wait for fill                                                │     │
│    │    └─► Update positions                                             │     │
│    └─────────────────────────────────────────────────────────────────────┘     │
│                                      │                                          │
│                                      ▼                                          │
│    ┌─────────────────────────────────────────────────────────────────────┐     │
│    │ 7. UPDATE STATE                                                     │     │
│    │    └─► Record trade                                                 │     │
│    │    └─► Update equity curve                                          │     │
│    │    └─► Log activity                                                 │     │
│    └─────────────────────────────────────────────────────────────────────┘     │
│                                      │                                          │
│                                      ▼                                          │
│                               SLEEP(interval)                                   │
│                                      │                                          │
│                                      └──────────────────────────────────────┐   │
│                                                                             │   │
```
